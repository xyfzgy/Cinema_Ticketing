# 影院售票系统项目说明

## 项目概述

本项目是一个前后端分离的影院售票系统，覆盖用户认证、电影与影院浏览、排片、座位选择、订单、秒杀、后台管理和 AI 客服等场景。后端代码位于 `springboot/`，前端代码位于 `vue/`，数据库脚本位于 `database/`，性能测试位于 `cinema-jmeter/`。

## 技术栈总览

- 后端：Java、Spring Boot 3.5、Spring MVC、Spring Security、Spring Validation、MyBatis-Plus、JWT、Lombok、Hutool。
- 数据与中间件：MySQL、Oracle、Redis、RabbitMQ；数据库脚本在 `database/`，MyBatis 按数据库类型放在 `resources/mapper/mysql` 和 `resources/mapper/oracle`。
- AI 与测试：Spring AI OpenAI 兼容接口、JMeter 压测脚本。
- 前端：Vue 3、Vite、Vue Router、Axios、Element Plus；源码在 `vue/src`，构建产物在 `vue/dist`。

## 典型实现路径

需求从前端页面或 API 发起，经 Controller 参数校验后进入 Service；Service 在事务中调用 Mapper 读写数据库，并按需使用 Redis 完成缓存、令牌、幂等或座位占用控制，使用 RabbitMQ 处理异步订单和秒杀消息；结果统一封装后返回前端。新增功能建议沿用“数据库表/状态规则 → Entity/DTO/VO → Mapper → Service → Controller → 前端 API 与页面 → 联调及 JMeter 验证”的顺序实现。
